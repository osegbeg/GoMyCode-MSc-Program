1\. Project Title

TaskFlow — Full-Stack Task \& Workflow Management Application

2\. Project Description

TaskFlow is a full-stack web-based task and workflow management application designed to help individuals and small teams organize daily work, track task progress, and meet deadlines without clutter or lost action items.

Problem It Solves:

Managing tasks across scattered sticky notes, chats, and spreadsheets leads to missed deadlines, unclear priorities, and poor visibility into what is pending versus completed. TaskFlow centralizes task creation, prioritization, status tracking, and deadline monitoring in a single responsive dashboard.

Core Features:

User Authentication \& Personal Workspaces: Secure user registration and login so each user manages their own private task board.

Complete Task CRUD Operations: Create, view, edit, and delete tasks with a title, detailed description, priority level (Low, Medium, High), category/tag, and due date.

Workflow Status Tracking: Move tasks across clear progress stages (To Do, In Progress, Completed) with one-click status updates.

Search, Filtering \& Sorting: Filter tasks by status, priority, or category, search by keyword, and sort by due date or priority.

Progress Summary Dashboard: Real-time overview showing total tasks, pending items, overdue tasks, and completion rate.

Responsive Interface: Clean, mobile- and desktop-friendly interface backed by a RESTful Node.js/Express API and persistent database storage.
