# React To-Do List Application

A clean, responsive To-Do List application built with React that demonstrates component-based architecture, state management with Hooks (`useState`, `useEffect`), form validation, and `localStorage` persistence.

## Features
- **Add Tasks:** Create tasks with a name and description, backed by input validation.
- **Edit Tasks:** Click on any task (or its Edit button) to load its details into the form and update them.
- **Complete Tasks:** Toggle tasks between active and completed states with clear visual styling.
- **Delete Tasks:** Remove tasks safely with a confirmation prompt.
- **Filter Tasks:** View All, Active, or Completed tasks.
- **Persistent Storage:** Automatically saves and restores tasks using browser `localStorage`.
